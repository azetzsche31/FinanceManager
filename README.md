# Finance Manager

Eine Desktop-Anwendung zur Verwaltung persönlicher Finanzen.

## Technologien

- Java 25 LTS
- Maven
- Git
- IntelliJ IDEA Community
- JavaFX (geplant)
- SQLite (geplant)

## Projektstatus

🚧 In Entwicklung

## Geplante Funktionen

- Konten verwalten
- Einnahmen und Ausgaben erfassen
- Kategorien verwalten
- Budgetplanung
- Sparziele
- Monats- und Jahresstatistiken
- Diagramme
- CSV-Import von Bankauszügen
